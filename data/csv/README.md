# WTI Average Price Option CSV data notes

The per-contract CSV histories under the maturity folders are the empirical WTI
Average Price Option inputs.  Two aggregate files were generated by
`data/build_option_series_properties.py`:

- `option_series_properties.csv`: diagnostics for every decoded option series;
- `richest_option_series.csv`: the 30 series with the highest **data-richness** score.

Here, **richest does not mean most liquid, best priced, or most economically
interesting**.  The existing score is deliberately a completeness score:

- 45% = number of observed sessions;
- 30% = calendar span;
- 25% = completeness of the eight numerical Barchart fields.

Consequently a zero-volume series with low open interest can still be `rich` if
it has a long, complete daily history.  The publication analysis therefore does
not use `richest_option_series.csv` as an estimation filter.

The empirical workflow uses three layers instead:

1. preserve all downloaded contract/date observations in the raw panel;
2. apply transparent quality/liquidity filters only in the main analysis and
   report sensitivity to those filters;
3. rank representative contracts separately for figures using history length,
   informative prices, open interest, effective ATM days, and moneyness
   crossings.

Expiry is decoded from the JAO symbol itself.  Folder names are treated as
provenance only because the current tree contains at least one apparent folder
mismatch (`JAOU8`, which is Sep-2028, inside `jun2029`).

See `research/EMPIRICAL_WTI_DESIGN.md` and `experiments/build_wti_apo_panel.py`.
