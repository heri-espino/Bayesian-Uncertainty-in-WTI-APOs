# Journal of Futures Markets submission checklist

This page mirrors issue [#42](https://github.com/heri-espino/Metropolis-Hastings-for-Asian-Options-Using-Bayesian-Inference-and-Black-Scholes--Article-/issues/42)
and should be used only after the scientific milestones are substantially closed.

## Scientific readiness

- [ ] Literature positioning is complete.
- [ ] The central novelty claim survives comparison with the final literature matrix.
- [ ] Forward-in-time empirical validation is finalized.
- [ ] Data provenance and settlement wording are final.
- [ ] Any richer-model robustness exercise selected for the paper is complete.
- [ ] Positive-volume limitations are stated without overclaiming.
- [ ] Main conclusions match the evidence in tables and figures.

## Manuscript readiness

- [ ] Final title.
- [ ] Final abstract.
- [ ] Final keywords.
- [ ] Corresponding-author email filled.
- [ ] "Internal working draft" marker removed.
- [ ] Acknowledgments completed.
- [ ] Figures/tables integrated and cited in order.
- [ ] Supplement assembled.
- [ ] Bibliography checked against source papers.
- [ ] Data availability statement final.
- [ ] Code availability statement final.
- [ ] Conflict-of-interest statement final.

## Reproducibility readiness

- [ ] `pytest` passes.
- [ ] Sphinx documentation builds with warnings as errors.
- [ ] GitHub Actions `build-paper` passes.
- [ ] Figure manifest reports `wiley-utopia-vendored`.
- [ ] Submission PDF is generated by the canonical workflow.
- [ ] Submission tag created.
- [ ] Code snapshot archived and DOI recorded if available.

## Upload package

- [ ] Main manuscript PDF/source.
- [ ] Figures in required format/resolution.
- [ ] Tables included in manuscript/source as required.
- [ ] Supplementary appendix.
- [ ] Cover letter.
- [ ] Data/code availability metadata.
- [ ] Author metadata and affiliations.
- [ ] Suggested reviewers only if requested by the journal.

Before upload, re-check the current Wiley/JFM author guidelines rather than relying on this
static checklist.
