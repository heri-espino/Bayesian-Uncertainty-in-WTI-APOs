##### Appendix 1. Derivation of the Black-Scholes Formula from Path Integrals

In this section, it is shown that the Feynman-Kac formula with Black-Scholes Lagrangian yields exactly the Black-Scholes closed-form result for European options following closely the work of Utama and Purqon (2016). In Section 2, the Feynman-Kac formula Equation (41) for a European call option was defined as

$$C ( x _ { 0 } , 0 ) = e ^ { - r T } \int _ { - \infty } ^ { \infty } \int _ { x _ { 0 } } ^ { x _ { T } } C ( e ^ { x _ { T } } ) e ^ { - S _ { B S } [ x ( t ) ] } \mathcal { D } [ x _ { T } ] d x _ { T } ,$$

where the Black-Scholes action functional was written as

$$S _ { \text {bs} } = \underbrace { \int _ { 0 } ^ { T } \frac { 1 } { 2 \sigma ^ { 2 } } \left ( \frac { d x } { d t } \right ) ^ { 2 } d t - \frac { \mu } { \sigma ^ { 2 } } ( x _ { T } - x _ { 0 } ) + \frac { \mu ^ { 2 } T } { 2 \sigma ^ { 2 } } , } _ { = S _ { 0 } [ x ( t ) ] }$$

and where S 0 represents the action of a zero drift process .

FromEquation (56), the constant terms can be further separated, so that the option value is written as

$$C ( x _ { 0 } , 0 ) = e ^ { - r T } \int _ { - \infty } ^ { \infty } \int _ { x _ { 0 } } ^ { x _ { T } } C ( e ^ { x _ { T } } ) e ^ { \frac { \mu } { \sigma ^ { 2 } } ( x _ { T } - x _ { 0 } ) - \mu ^ { 2 } T / 2 \sigma ^ { 2 } } e ^ { - S _ { 0 } [ x ( t ) ] } \mathcal { D } [ x _ { T } ] d x _ { T } ,$$

Recalling the discretization of the transition probability and expressing the integral over paths using Equation (46) it can be show that

$$p ( x _ { T } , T | x _ { 0 } , 0 ) & = \int _ { x _ { 0 } } ^ { x _ { T } } \mathcal { D } [ x _ { T } ] e ^ { - S _ { \delta } } \\ & = \lim _ { N \to \infty } \left [ \prod _ { k = 0 } ^ { N - 1 } \int _ { - \infty } ^ { \infty } \frac { d x _ { k } } { \sqrt { 2 \pi \sigma ^ { 2 } \delta t _ { k } } } \right ] e ^ { - S _ { \delta } } \\ & = \lim _ { N \to \infty } \underbrace { \int _ { - \infty } ^ { \infty } \cdots \int _ { - \infty } ^ { \infty } \exp \left \{ - \sum _ { k = 0 } ^ { N - 1 } \frac { \Delta t } { 2 \sigma ^ { 2 } } \left ( \frac { x _ { k + 1 } - x _ { k } } { \Delta t } \right ) ^ { 2 } \right \} } _ { N - 1 } \\ & \quad \times \frac { 1 } { \sqrt { 2 \pi \sigma ^ { 2 } \delta t } } \times \frac { d x _ { 1 } } { \sqrt { 2 \pi \sigma ^ { 2 } \delta t } } \times \cdots \times \frac { d x _ { N - 1 } } { \sqrt { 2 \pi \sigma ^ { 2 } \delta t } }$$

$$& = \lim _ { N \to \infty } \frac { 1 } { \sqrt { 2 \pi \sigma ^ { 2 } N \delta t } } \exp \left \{ - \frac { ( x _ { N } - x _ { 0 } ) ^ { 2 } } { 2 \sigma ^ { 2 } N \delta t } \right \} \\ & = \frac { 1 } { \sqrt { 2 \pi \sigma ^ { 2 } T } } \exp \left \{ - \frac { ( x _ { T } - x _ { 0 } ) ^ { 2 } } { 2 \sigma ^ { 2 } T } \right \} ,$$

where the following Gaussian integral was used

$$\int _ { - \infty } ^ { \infty } e ^ { - a ( p - x ) ^ { 2 } - b ( x - q ) ^ { 2 } } d x = \sqrt { \frac { \pi } { a + b } } \exp \left \{ - \frac { a b } { a + b } ( p - q ) ^ { 2 } \right \} .$$

Putting the pieces from Equations (57) and (58) together, the price of the option can be expressed as

$$C ( x _ { 0 } , t ) = e ^ { - r T } \int _ { - \infty } ^ { \infty } C ( e ^ { x _ { T } } \frac { 1 } { \sqrt { 2 \pi \sigma ^ { 2 } T } } \exp \left \{ - \frac { ( x _ { T } - x _ { 0 } - \mu T ) ^ { 2 } } { 2 \sigma ^ { 2 } T } \right \} d x _ { T } ,$$

from which the Gaussian integral can again be exactly solved, yielding exactly the BlackScholes formula, Equation (29)

$$C = S \mathcal { N } ( d _ { 1 } ) - K e ^ { - r T } \mathcal { N } ( d _ { 2 } ) ,$$

where

$$d _ { 1 } = \frac { \ln \left ( \frac { S } { K } \right ) + \left ( r + \frac { \sigma ^ { 2 } } { 2 } \right ) T } { \sigma \sqrt { T } }$$

$$d _ { 2 } = d _ { 1 } - \sigma \sqrt { T }$$

and the payoff function

$$C ( e ^ { x _ { T } } ) = \max \left \{ 0 , e ^ { x _ { T } } - K \right \}$$

was used.
