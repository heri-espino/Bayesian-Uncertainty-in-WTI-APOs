\title{When Does Posterior Integration Change Option Values? Evidence from WTI Average Price Options}

\author[1]{Heriberto Espino Montelongo}
\authormark{ESPINO MONTELONGO}
\titlemark{POSTERIOR INTEGRATION IN WTI AVERAGE PRICE OPTIONS}

\address[1]{\orgname{Universidad de las Am\'ericas Puebla}, \orgaddress{\state{Puebla}, \country{Mexico}}}
\corres{Corresponding author: Heriberto Espino Montelongo. \email{[corresponding email]}}

\abstract[Abstract]{
Option prices depend on volatility estimates, and those estimates are uncertain. This paper asks when averaging a WTI Average Price Option value over the historical-volatility posterior changes the price relative to using posterior mean volatility. A second-order approximation relates the difference between posterior-integrated and posterior-mean plug-in prices (PI and PM) to posterior variance and the curvature of the option price with respect to volatility. An experiment using 175,000 synthetic return histories shows that the difference can be important with short historical samples and strong price curvature. In the observed October-2026 WTI sample, the mean absolute PI--PM difference is only \$0.000745 per barrel, although the mean width of the 95\% posterior interval for the model price is \$0.2733 per barrel. A small difference in mean prices therefore does not imply little parameter uncertainty in model prices. On 2,381 out-of-sample contract-date observations, implied volatility estimated from earlier option observations yields much lower pricing errors than the historical-volatility benchmarks evaluated here. Rolling-window, exponentially weighted, and horizon-matched GARCH estimates do not achieve comparable performance. The improvement does not require a flexible implied-volatility smile and remains when volatility is inferred from standard monthly WTI futures options. These conclusions apply to the tested inputs and the maintained one-factor pricing model.
}

\bmsection*{Data availability}
The APO and CL histories used in the empirical application were obtained through a commercial Barchart subscription. The independent vanilla-WTI validation uses CME/NYMEX LO option and CL futures statistics accessed through Databento. Redistribution of raw proprietary market-data files is not assumed to be permitted. The public repository therefore prioritizes code, query metadata, schemas, provenance records, diagnostics, hashes, and derived results consistent with the applicable data licenses.

\bmsection*{Code availability}
The research code is organized as an installable Python package, \texttt{bayesian\_asian\_options}, with documented APIs, tests, deterministic seeds, reproducible experiment entry points, and committed derived results. The public repository is \url{https://github.com/heri-espino/Bayesian-Uncertainty-in-WTI-APOs}. The submitted manuscript and figures will be tied to the exact Git commit used for the submission build; that commit will be preserved as the versioned submission snapshot.
