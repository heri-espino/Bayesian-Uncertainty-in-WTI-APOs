\abstract[Abstract]{
We examine how historical-volatility parameter uncertainty affects WTI Average Price Option (APO) values and compare historical with option-implied volatility inputs. The posterior-integrated price (PI) averages conditional values over the volatility posterior, whereas the posterior-mean plug-in price (PM) uses posterior mean volatility. A second-order approximation relates the PI--PM difference to posterior variance and price curvature. Across 175,000 synthetic return histories, posterior integration can materially affect values when historical samples are short and curvature is pronounced. In the October-2026 WTI sample, however, the mean absolute PI--PM difference is only \$0.000745 per barrel, despite a mean width of \$0.2733 per barrel for the central 95\% posterior interval of model prices. Posterior price dispersion is therefore not captured by the PI--PM difference. In 2,381 out-of-sample APO observations, implied volatility estimated from earlier option dates produces substantially lower pricing errors than the historical-volatility benchmarks tested, including rolling windows, EWMA, and horizon-matched GARCH. The advantage does not require fitting a volatility smile and persists when implied volatility is inferred from standard monthly WTI futures options. These findings are conditional on the observed sample and the maintained one-factor pricing model.
}

\bmsection*{Data availability}
The APO and CL histories used in the empirical application were obtained through a commercial Barchart subscription. The independent vanilla-WTI validation uses CME/NYMEX LO option and CL futures statistics accessed through Databento. Redistribution of raw proprietary market-data files is not assumed to be permitted. The public repository therefore prioritizes code, query metadata, schemas, provenance records, diagnostics, hashes, and derived results consistent with the applicable data licenses.

\bmsection*{Code availability}
The research code is organized as an installable Python package, \texttt{bayesian\_asian\_options}, with documented APIs, tests, deterministic seeds, reproducible experiment entry points, and committed derived results. The public repository is \url{https://github.com/heri-espino/Bayesian-Uncertainty-in-WTI-APOs}. The submitted manuscript and figures will be tied to the exact Git commit used for the submission build; that commit will be preserved as the versioned submission snapshot.
