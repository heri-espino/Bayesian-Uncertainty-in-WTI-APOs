\title{When Does Posterior Integration Change Option Values? Evidence from WTI Average Price Options}

\author[1]{Heriberto Espino Montelongo}
\authormark{ESPINO MONTELONGO}
\titlemark{POSTERIOR INTEGRATION IN WTI AVERAGE PRICE OPTIONS}

\corres{Corresponding author: Heriberto Espino Montelongo. \email{[corresponding email]}}

\abstract[Abstract]{
Option prices depend on estimated volatility, and those estimates are uncertain. We study when averaging a WTI Average Price Option value over a Bayesian volatility posterior changes the result relative to using posterior mean volatility. The difference between the posterior-integrated price (PI) and the posterior-mean plug-in price (PM) depends locally on posterior variance and the curvature of the option price with respect to volatility. An experiment using 175,000 synthetic return histories shows that this difference can be important with short historical samples and strong price curvature. In the observed October-2026 WTI sample, however, the mean absolute PI--PM difference is \$0.000745 per barrel, although the mean width of the 95\% posterior interval for the model price is \$0.2733 per barrel. A small PI--PM difference therefore does not imply little uncertainty about the model price. We also compare volatility inputs on 2,381 out-of-sample contract-date observations. Implied volatility estimated from earlier option observations gives much lower pricing errors than the historical-volatility benchmarks tested, including rolling-window, exponentially weighted, and horizon-matched GARCH estimates. The improvement does not require fitting a flexible implied-volatility smile and remains when the implied volatility comes from a separate vanilla-WTI option market. All comparisons are conditional on the maintained one-factor pricing model.
}

\bmsection*{Data availability}
The WTI APO and CL histories used in the empirical application were obtained through a commercial Barchart subscription. The independent vanilla-WTI validation uses CME/NYMEX LO option and CL futures statistics accessed through Databento. Raw proprietary market-data files are not redistributed. The public repository provides code, query metadata, schemas, provenance records, diagnostics, hashes, and derived results consistent with the applicable data licenses.

\bmsection*{Code availability}
The research code is organized as the Python package \texttt{bayesian\_asian\_options}, with tests, deterministic experiment entry points, and committed derived results. The public repository is \url{https://github.com/heri-espino/Bayesian-Uncertainty-in-WTI-APOs}.
