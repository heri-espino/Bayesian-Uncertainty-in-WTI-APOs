\section{Data and empirical design}\label{sec:short_design}

\subsection{WTI Average Price Options}

The first empirical dataset contains Barchart price histories for individual WTI Average Price Option contracts. The raw archive contains 213 unique contracts and 11,179 contract-date observations, with expiry months ranging from September 2026 to June 2029. We compare model prices with the Barchart end-of-day \texttt{Latest} field, treated as a settlement-price proxy. It has not been independently certified as an official final exchange settlement or executable transaction quote. We include available calls and puts and calculate moneyness separately for each valuation date.

For every observation, we identify the fixings already known and the futures contracts used for the remaining fixings. We initialize those contracts with the futures prices observed on the valuation date. This matters because the first-nearby contract can change during the averaging month.

Historical volatility is estimated from WTI futures returns available by the valuation date. The baseline estimates historical volatility from the continuous/front-month \texttt{CL=F} return series. A robustness check reconstructs a first-nearby return history contract by contract from CL settlements and excludes returns spanning contract switches.

\subsection{Date-ordered conditional pricing comparisons}

We compare volatility inputs by repricing APOs on later dates.
The option observations used to estimate implied volatility are
dated before each valuation date in the archived files. However,
we cannot independently verify when the vendor first published
the records or whether they were subsequently revised. Each price
uses the futures curve, known fixings, and discount factor on the
valuation date, while implied volatility comes from earlier
option observations. Historical-volatility estimates use the
specified return-data cutoff. This is a date-ordered conditional
pricing comparison, not proof that all records were available
in real time. The sample contains 2,381 contract-date
observations across seven expiries and 15 valuation dates.

The baseline integrates conditional prices over a volatility posterior estimated from an expanding return sample available at the stated valuation cutoff. The exercise evaluates conditional pricing errors using that day's observed futures curve and fixings, not prices forecast before those inputs became available. Historical alternatives use rolling windows of 63, 126, or 252 returns, an exponentially weighted moving average (EWMA) with a 63-business-day half-life, and a horizon-matched Gaussian GARCH(1,1) forecast. For GARCH, parameters are estimated from earlier returns; a valuation-date futures return updates conditional variance, which is then forecast over the remaining fixings. The GARCH comparison therefore also uses end-of-day information from the valuation date. It is not a forecast using only earlier-day information. We express these forecasts as the constant annualized volatility that gives the same variance for the remaining average under the one-factor pricing model. Full comparisons are in Online Supplement Section S1 and Table S1.

We obtain contract-level APO implied volatilities by inverting the Curran pricing approximation. For each expiry, the previous-day implied-volatility smile is estimated on the latest available earlier date. Another specification estimates a smile from all earlier dates, with greater weight on recent observations. Both depend on moneyness and option type. Neither uses the target-date APO settlement to estimate volatility.

To assess the value of smile fitting, we also carry forward each contract's most recent implied volatility. We reprice with the valuation-date curve, discount factor, and fixing schedule. This same-contract benchmark covers 2,366 observations.

Pricing performance is summarized by mean error, mean absolute error (MAE), and root mean squared error (RMSE). We use a cluster bootstrap that resamples valuation dates, keeping observations from the same date together.

\subsection{Cross-instrument validation}

The first comparison estimates implied volatility using earlier APO observations. We therefore add a cross-instrument check using standard monthly American WTI futures options (CME product LO) from Databento. We match LO option settlements to the underlying CL futures and invert prices using a Cox--Ross--Rubinstein futures-option tree.

For each APO target date, only LO observations from earlier dates are used. Implied-volatility smiles are fitted separately for the underlying CL futures contracts needed by the October-2026 APO fixing schedule. The resulting maturity-specific volatilities are mapped into the maintained scalar-volatility APO pricing model. We compare 253 APO contract-date observations over 10 target dates for which both external specifications can be evaluated within the moneyness range observed in earlier LO data. Online Supplement Section S4 and Table S4 report checks of the constant-volatility mapping and the number of steps in the Cox--Ross--Rubinstein tree.

This check asks whether the lower pricing errors also hold when implied volatility comes from a different WTI option product. It does not measure a variance risk premium.


\subsection{Separate Databento settlement-price comparison}

We examine the volatility-input comparison in a second dataset of
AAO settlement records from Databento. This is \emph{not} an extension
of the earlier Curran model using CL fixing paths. The datasets,
pricing methods, and information available for valuation differ. The Databento AAO
definitions and settlement statistics cover January 2020--September
2026; admissible evaluation dates run from January 2023 through
September 2026. We select every fifth available source date and apply the same
contract eligibility rules throughout, obtaining 189 valuation dates,
1,689 expiry-date groups, and 111,585 contract-date observations. Of these,
97,341 are classified by the data provider as actual
settlements and 14,244 as theoretical. All headline
error comparisons below use the 97,341 observations
classified as actual.

We estimate the risk-neutral expected terminal average and an
effective discount factor by fitting put--call parity to a separate
set of matched call and put strikes on the valuation date. Those
strikes are excluded from the options used to evaluate pricing errors. The subsequent price is the
reduced-form Black price of a \emph{lognormal terminal arithmetic
average}, not the Curran approximation applied to a simulated path of
first-nearby CL fixes. Because the pricing inputs use other AAO settlement prices from
the same date, this is a conditional comparison, \emph{not} a
forecast made entirely with earlier information.

The historical-volatility input is estimated from earlier changes
in the expected AAO average inferred from put--call parity for
the same expiry. It is therefore neither a history of CL futures
returns nor a risk-neutral volatility estimate. Posterior integration (PI) and
posterior-mean plug-in (PM) use the same return-proxy posterior.
Rolling and exponentially weighted proxies are evaluated on
exactly the same option targets. The simple implied-volatility benchmark carries forward volatility
inferred from near-the-money AAO option prices on an earlier date,
using the \emph{same} terminal-average pricing model. No implied
volatility from the valuation date is used as an input to this
benchmark. All six methods are evaluated on the same contracts
and dates.

A second exercise uses only \emph{strictly earlier} near-the-money
AAO implied volatilities to model changes in log implied
volatility for each expiry. Bayesian normal-inverse-gamma updating yields a
Student-\(t\) posterior predictive log-volatility distribution:
\texttt{bayes\_IV\_PI} averages option prices over 256 predictive
volatility draws; \texttt{bayes\_IV\_PM} prices at their mean.
Both are compared with the price obtained by carrying forward
the last observed implied volatility for the same options. The chronological comparison is reported separately
for 2023--2024 development dates and 2025--September 2026;
the latter dates had already been inspected during initial work and
are not an untouched confirmatory holdout for every subsequent
diagnostic.

In a separate analysis, we construct 90\% and 95\% prediction
intervals for errors between observed settlement prices and model prices,
using either a Bayesian normal-inverse-gamma model fitted to
past errors with equal weight across dates or rolling empirical
quantiles of past errors. It uses a 63-date maximum window, requires
at least 15 earlier dates per put/call-side and maturity stratum,
and evaluates the intervals using observed coverage, width,
and the interval score. These are \emph{not} posterior credible
intervals for an Asian payoff, nor posterior price bands from
the volatility parameter in the earlier October-expiry study.
We resample by valuation date or calendar month for paired
comparisons, rather than treating contracts on the same date
as independent observations.
